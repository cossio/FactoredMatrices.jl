FactoredMatrices.FactoredMatrix — Type
FactoredMatrix(u, v)

A lazy matrix stored as the product u * v', where u is m × r and v is n × r (typically with r < m, n). The resulting matrix has size m × n and rank at most r.

The full dense matrix can be recovered with Matrix(A). Operations such as scalar multiplication, matrix products, adjoint, transpose, and svd exploit the factored representation and return FactoredMatrix results where possible.

If u or v are vectors, they are treated as m × 1 or n × 1 matrices, respectively. If u and v have different element types, both are converted to their promoted element type.

LinearAlgebra.svd — Method
svd(A::FactoredMatrix)

Compute the singular value decomposition of A, exploiting the factored representation. Only QR decompositions of the factors and an SVD of the min(m, r) × min(n, r) core are required, which is cheaper than an SVD of the materialized full matrix when r < m, n.

Returns a reduced LinearAlgebra.SVD factorization object with min(m, n, r) singular values, where U is m × min(m, n, r) and Vt is min(m, n, r) × n. When r < min(m, n) this is smaller than the factorization returned by svd(Matrix(A)), which has min(m, n) singular values; the omitted singular values are all zero.
